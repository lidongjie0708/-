# 上下文分层组装规范（L0-L4）

本文件是给上下文构建器（代码）的规范，不是给模型的系统提示。

## 分层与预算

| 层 | 内容 | 预算 | 裁剪优先级 |
| --- | --- | --- | --- |
| L0 | 系统层：角色、安全规则、工具说明 | 不裁剪 | - |
| L1 | 长期记忆（跨会话召回） | ≤ 600 tokens | 最后裁，按 importance 降序保留 |
| L2 | 短期记忆（本会话轮次） | ≤ 800 tokens | 次之 |
| L3 | 即时层：问题、分析计划、查询结果 | 剩余预算 | 最先裁 |
| L4 | 输出层：格式与三段式约束 | 不裁剪 | - |

## 组装顺序

按 L0 → L1 → L2 → L3 → L4 固定顺序拼接，每层使用明确分隔标记：

```text
<layer name="system">
...
</layer>
<layer name="long_memory">
...
</layer>
<layer name="short_memory">
...
</layer>
<layer name="immediate">
问题、计划、查询结果
</layer>
<layer name="output_format">
...
</layer>
```

## 预算超限时的收缩顺序

1. 先裁 L3：截断工具结果到前 N 行并标注「结果已截断，共 X 行」；仍超限再截断分析计划。
2. 再裁 L2：按短期记忆压缩规则，先裁剪工具结果，再合并老轮次。
3. 最后裁 L1：按 importance 降序丢弃低重要性记忆。
4. L0 与 L4 永不裁剪。

## 规则

- L1、L2 内容必须标注来源（memory），模型不得把它们当作本次查询的事实。
- 每次裁剪都要生成裁剪报告：层名、裁剪原因、节省的 token 数、剩余预算。
- 预算数值从 settings 读取（默认见 README），压测时可调。
